Draw one straight line through a year of prices.

A small Flask app that fits a single straight line to a year of daily closes and extends it five trading days. It exists to show how little that tells you, and to measure it.

Try the demo Run the real app

Demo on simulated prices

Each run is a random walk with no trend built in, so any line you see is chance. The line is fitted to the first 252 days and continued five days. The real app runs the same method in Python on Yahoo Finance data. This page never loads real prices.

How it works

  1. Download about a year of daily closes (adjusted) from Yahoo Finance with yfinance.
  2. Number the days 0, 1, 2 and so on and fit price = a + b × day by least squares.
  3. Extend the line five trading days past the last close.
  4. Replay the year: every fifth day from day 20, fit a line to the prices so far, extend it five days and compare with what happened. Score a naive guess (the last close stays) the same way.

The backtest uses the same year the page shows. It is a sanity check, not proof the line will work. Free data can be late, wrong or missing, and the model ignores earnings, news, rates and volatility.

Run the real app

Needs Python 3.11 or newer. There is no hosted version.

git clone https://github.com/patrickking67/stock-predictor.git
cd stock-predictor
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
scripts/dev.sh   # http://127.0.0.1:4110

An Alpha Vantage key is optional and stays on the server. Never put a key in a web page.
